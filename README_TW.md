## 為什麼需要這個工具

AFK 農業循環需要知道何時可以種植、庫存何時已滿以及遊戲窗口是否仍處於活動狀態。每個狀態都會出現在循環編輯器中，並且可以停止會話，而不是讓輸入盲目地繼續。

## 主要功能

### 01 · 種植和收集循環

將延遲和檢測設定儲存為可重複使用的配置文件，而不是鬆散的數字。

### 02 · 庫存滿檢測

顯示目前循環期間識別的確切螢幕區域和狀態。

### 03 · 視窗焦點和停止規則

在限制、失去焦點、斷開連接或緊急鑰匙處停止並記錄原因。

## 介面說明

- **01.** 用於「種植」、「等待」、「收集」和「補貨」步驟的循環編輯器。
- **02.** 花園預覽顯示目前偵測到的繪圖狀態。
- **03.** 庫存容量計和滿停規則。
- **04.** 窗口焦點和斷開防護裝置。
- **05.** 包含收集項目、週期和停止原因的會話日誌。

## 如何理解結果

在判斷輸入時序之前先讀取帶電偵測器。在螢幕狀態正確的情況下錯過的操作會導致延遲；空白或不穩定狀態指向偵測區域。會話計數器有助於確認一項調整是改善整個循環還是僅將故障轉移到另一個步驟。

## 開始之前

- 準備好 **時序設定檔+螢幕狀態**，並確認它屬於目標 Plants vs Brainrots (Roblox) 設定或連線。
- 變更設定之前，記錄目前遊戲/用戶端版本或資料日期。
- 先選擇 **個人資料和會話日誌** 的儲存位置，避免覆蓋上一次結果。
- 先用 **種植和收集循環** 進行一次短測試，並保留原始存檔、設定或比較記錄。

## 資料與還原

保持緊急鍵啟用，限制第一個會話並在調整之前保存已知良好的設定檔。日誌應該記錄循環停止的原因，而不僅僅是運行了多長時間。

<sub>自動化與修改功能僅限遊戲規則和目前連線類型允許時使用。</sub>

## 完成第一次使用

1. 開啟 **Plants vs Brainrots 掛機收集巨集**，確認偵測到的 Plants vs Brainrots (Roblox) 版本或資料來源。
2. 選擇輸入或設定，只調整 **種植和收集循環**，先保留與本次測試無關的預設值。
3. 在預覽或狀態面板檢查 **庫存滿檢測**，處理版本、篩選或辨識警告。
4. 只執行一次可控制的操作。在修改第二項設定之前，將實際結果與預覽比較。
5. 儲存設定或匯出結果，並保留 **視窗焦點和停止規則** 以便比對或還原。

## 遊戲更新之後

- [ ] 開啟即時視圖並確認目前 UI 比例下的每個偵測區域。
- [ ] 在重新使用無人值守設定檔之前執行一個簡短的上限會話。
- [ ] 僅在會話日誌識別出錯過的狀態後才會更改一個延遲。
- [ ] 保持先前的配置文件，直到確認接球、停止和聚焦行為。

## 問題排查

> **常見問題:** 庫存滿後繼續循環.

### 循環錯過了一個螢幕

開啟即時視圖並以目前解析度和 UI 比例重新繪製偵測區域。

### 在另一個視窗中繼續輸入

在開始長時間會話之前啟用前台防護並測試緊急熱鍵。

### 更新後時間發生了變化

複製舊的配置文件，調整一個延遲並比較會話日誌，而不是編輯每個值。
