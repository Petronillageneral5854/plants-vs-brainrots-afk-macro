## このツールが必要な理由

AFK ファーミング ループは、いつ植え付けが可能か、いつインベントリがいっぱいになるか、ゲーム ウィンドウがまだアクティブかどうかを知る必要があります。各状態はループ エディターに表示され、入力を盲目的に続行させる代わりにセッションを停止できます。

## できること

### 01 · 植栽と収集のループ

遅延と検出設定を、緩い数値ではなく再利用可能なプロファイルとして保存します。

### 02 · 在庫満杯の検出

現在のループ中に認識された正確な画面領域と状態を表示します。

### 03 · ウィンドウのフォーカスと停止のルール

限界で停止、フォーカスを失った、切断または緊急キーで停止し、その理由を記録します。

## 画面の見方

- **01.** Plant、Wait、Collect、Restock ステップのループ エディター。
- **02.** 現在検出されている区画の状態を示す庭のプレビュー。
- **03.** 在庫容量メーターとフルストップルール。
- **04.** ウィンドウのフォーカスとガードの切断。
- **05.** 収集されたアイテム、サイクル、停止理由を含むセッション ログ。

## 機能の概要

| 機能 | 結果 |
|---|---|
| **入力** | タイミングプロファイル + 画面状態 |
| **結果** | 制御された入力ループ |
| **出力** | プロフィールとセッションログ |

## こんな用途に

- 再現可能なタイミングプロファイルを構築する
- 見逃した UI 状態をキャッチする
- 状況が変化したときは安全に停止してください

## 結果の読み方

入力タイミングを判断する前にライブディテクタを読み取ってください。正しい画面状態でアクションが実行されなかった場合は、遅延が発生していることを示します。空白または不安定な状態は、検出領域を示します。セッション カウンターは、1 つの調整によってループ全体が改善されるのか、それとも障害が別のステップに移行するだけなのかを確認するのに役立ちます。

## 開始前の準備

- **タイミングプロファイル + 画面状態** を用意し、対象の Plants vs Brainrots (Roblox) プロファイルまたはセッションのものか確認します。
- プロファイルを変更する前に、現在のゲーム／クライアントビルドまたはデータ日付を控えます。
- 前回の結果を上書きしないよう、**プロフィールとセッションログ** の保存先を決めます。
- まず **植栽と収集のループ** を短時間だけ試し、元のセーブ、プロファイル、比較結果を残してください。

## データと復元

緊急キーを有効にしたままにし、最初のセッションにキャップを付け、調整する前に正常であることがわかっているプロファイルを保存します。ログには、ループの実行時間だけでなく、ループが停止した理由も記録する必要があります。

<sub>自動化や変更機能は、ゲームのルールとセッション形式で許可されている場合にのみ使用してください。</sub>

## 初回の一連の流れ

1. **Plants vs Brainrots 放置周回マクロ** を開き、検出された Plants vs Brainrots (Roblox) のビルドまたはデータ元を確認します。
2. 入力またはプロファイルを選び、今回のテストに関係しない初期値は変えずに **植栽と収集のループ** を設定します。
3. プレビューまたはステータス欄で **在庫満杯の検出** を確認し、バージョン、フィルター、検出の警告を解消します。
4. 操作を一つだけ実行します。二つ目の設定を変える前に、表示結果をプレビューと比較してください。
5. プロファイルまたは結果を保存し、比較や復元に使える **ウィンドウのフォーカスと停止のルール** を残します。

## ゲーム更新後の確認

- [ ] ライブ ビューを開いて、現在の UI スケールですべての検出領域を確認します。
- [ ] 無人プロファイルを再利用する前に、短い制限付きセッションを実行してください。
- [ ] セッション ログで欠落状態が特定された後でのみ、遅延を 1 つ変更してください。
- [ ] キャッチ、停止、フォーカス動作が確認されるまで、以前のプロファイルを保持します。

## トラブルシューティング

> **よくある不具合:** インベントリがいっぱいになった後もループは継続します.

### ループが画面を見逃します

ライブ ビューを開き、現在の解像度と UI スケールで検出領域を再描画します。

### 入力は別のウィンドウで続行されます

長いセッションを開始する前に、フォアグラウンド ガードを有効にし、緊急ホットキーをテストします。

### アップデート後にタイミングが変更されました

すべての値を編集するのではなく、古いプロファイルを複製し、1 つの遅延を調整してセッション ログを比較します。
