## 为什么需要这个工具

AFK 农业循环需要知道何时可以种植、库存何时已满以及游戏窗口是否仍处于活动状态。每个状态都会出现在循环编辑器中，并且可以停止会话，而不是让输入盲目地继续。

## 它能做什么

### 01 · 种植和收集循环

将延迟和检测设置存储为可重复使用的配置文件，而不是松散的数字。

### 02 · 库存满检测

显示当前循环期间识别的确切屏幕区域和状态。

### 03 · 窗口焦点和停止规则

在限制、失去焦点、断开连接或紧急钥匙处停止并记录原因。

## 界面说明

- **01.** 用于“种植”、“等待”、“收集”和“补货”步骤的循环编辑器。
- **02.** 花园预览显示当前检测到的绘图状态。
- **03.** 库存容量计和满停规则。
- **04.** 窗口焦点和断开防护装置。
- **05.** 包含收集项目、周期和停止原因的会话日志。

## 如何理解结果

在判断输入时序之前先读取带电检测器。屏幕状态正确的情况下错过的操作会导致延迟；空白或不稳定状态指向检测区域。会话计数器有助于确认一项调整是改善整个循环还是仅将故障转移到另一步骤。

## 开始之前

- 准备好 **时序配置文件+屏幕状态**，并确认它属于目标 Plants vs Brainrots (Roblox) 配置或会话。
- 更改配置之前，记录当前游戏/客户端版本或数据日期。
- 提前选择 **个人资料和会话日志** 的保存位置，避免覆盖上一次结果。
- 先用 **种植和收集循环** 进行一次短测试，并保留原始存档、配置或对比记录。

## 数据与恢复

保持紧急键启用，限制第一个会话并在调整之前保存已知良好的配置文件。日志应该记录循环停止的原因，而不仅仅是运行了多长时间。

<sub>自动化与修改功能仅应在游戏规则和当前会话类型允许的情况下使用。</sub>

## 完成第一次使用

1. 打开 **Plants vs Brainrots 挂机收集宏**，确认检测到的 Plants vs Brainrots (Roblox) 版本或数据源。
2. 选择输入或配置，只设置 **种植和收集循环**，暂时保留与本次测试无关的默认值。
3. 在预览或状态面板检查 **库存满检测**，处理版本、筛选或识别警告。
4. 只执行一次可控操作。在修改第二项设置之前，将实际结果与预览进行对比。
5. 保存配置或导出结果，并保留 **窗口焦点和停止规则** 以便对比或恢复。

## 游戏更新之后

- [ ] 打开实时视图并确认当前 UI 比例下的每个检测区域。
- [ ] 在重新使用无人值守配置文件之前运行一个简短的上限会话。
- [ ] 仅在会话日志识别出错过的状态后才更改一个延迟。
- [ ] 保持先前的配置文件，直到确认接球、停止和聚焦行为。

## 故障排查

> **常见故障:** 库存满后继续循环.

### 循环错过了一个屏幕

打开实时视图并以当前分辨率和 UI 比例重新绘制检测区域。

### 在另一个窗口中继续输入

在开始长时间会话之前启用前台防护并测试紧急热键。

### 更新后时间发生了变化

复制旧的配置文件，调整一个延迟并比较会话日志，而不是编辑每个值。
